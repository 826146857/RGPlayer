# RGPlayer 使用说明（v0.40.2）

面向 ANBERNIC RG Rotate（720×720 方屏、Android 12）的本地视频播放器。与 MX Player 没有任何依赖或联动。

## 安装

- APK：`RGPlayer-0.40.2.apk`（本目录）
- 安装：拷贝到机器上点击安装，或 `adb install -r RGPlayer-0.25.0.apk`
- 首次启动需要「媒体/视频」读取权限；授权后自动扫描视频

## 回滚

- 本项目不修改系统，也不动其它播放器的数据
- 回滚旧版本：先卸载当前版本，再安装你保存的旧 APK 即可
- 设置数据存在应用私有目录，卸载会一起清掉；需要保留设置就先备份（本版不提供导出功能）
- 校验：`RGPlayer-0.40.2.apk.sha256` 是本次 APK 的 SHA256

## 界面

- 首页：显示「视频所在目录的上一级」，点文件夹进入下一层，左上角返回逐级向上
- 右下角齿轮只在首页（根目录）出现
- 视频卡片：封面（自定义图片或首帧）、时长、播放进度

## 覆盖 / 缩略图

- 播放器**不生成缩略图文件**，只读取你自己放的图片
- 命名规则（放进视频同目录，大小写敏感）：
  1. 与视频同名：`Movie.mkv` → `Movie.jpg` / `.jpeg` / `.png` / `.webp`
  2. 目录级：`poster.jpg`（该目录所有视频共用）
- 没有封面时，临时读视频第一帧；纯黑/纯白/纯色卡会往后跳（5s/10s/20s/30s/10%/25%/50%），只放内存
- 设置 →「清除缓存」可清空内存封面与缓存目录

## 播放与手势

- 单击：显示/隐藏控制层
- 双击：暂停/继续播放
- 左右滑：快退/快进（松手生效，显示目标时间）
- 拖动进度条：显示目标位置的预览画面
- 上下滑：左半屏亮度（无级）、右半屏应用内音量（无级）
- 长按画面：进入调速，左右滑动 0.5×–4.0×（默认 1.0×），松手恢复
- 双指捏合：画面 1.0×–3.0× 缩放；双指拖动平移
- 侧边返回 / 导航返回：退出播放；手柄 Start/Menu：打开功能菜单

## 手柄

- A / 回车 / 空格：播放暂停
- B：退出播放器
- 十字左右：快退/快进 10 秒
- 十字上下：无功能（音量用机身音量键）
- L1 / R1：上一个/下一个视频
- Start / Menu：打开功能菜单

## 功能菜单

主菜单：画面比例 / 播放速度 / 字幕与音轨 / 播放列表 / 更多

- 画面比例：原画（留黑边）/ 沉浸（裁满），只对当前播放生效
- 播放速度：0.5×–4.0×，会记住为默认速度
- 字幕与音轨：选择音轨、选择字幕轨道、加载外挂字幕（srt/ass/vtt）、字幕开关
- 字幕/音轨选择按视频记忆，下次自动恢复
- 播放列表：可视队列，显示当前项与进度百分比
- 更多：视频信息（分辨率/码率/编码/帧率）、缩放（100/125/150/200%）、退出播放

## 设置\n\n- 字体：系统字体 / 内置字体（已打包你的系统字体）

- 默认画面比例（倍速固定 1.0×，播放中可长按/菜单临时调）
- （已移除滑动/双击开关：相关手势始终生效）
- 媒体目录：只显示指定目录（含子目录），长按恢复「全部」
- 隐藏 .nomedia 目录
- 响度均衡、立体声扩展、自动下一集、记住播放位置：内部固定开启，不再显示开关
- 立体声扩展（单扬声器虚拟声场）
- 自动下一集（播完自动切下一个，末集显示「播放结束」）
- 记住播放位置
- 说明：封面/手柄/隐藏规则/缓存
- 清除缓存：只清理媒体库里已删除视频的缓存（响度/进度/音轨/字幕记忆），不清在库视频

## 已知限制

- EAC3 / DTS 等音频依赖打包的 FFmpeg 解码器；极个别编码可能无声
- 不支持网络播放（HTTP/SMB/DLNA），只读 MediaStore 里的本地视频
- 卡上出现的 `.thumbnails` 目录是系统媒体库或其它播放器生成的，不是本应用写的
- 音量滑动是应用内音量（无级）；机身音量键调的是系统音量（系统分档）

## 构建

```
cd anbernic\work\player\rgplayer
.\build.ps1
```

- 需要 JDK 17、Android SDK（见 `build.ps1` 里的路径设置）
- 产物：`app\build\outputs\apk\debug\app-debug.apk`
- 使用 debug 签名（证书 SHA256：`1E:08:A9:03:AE:F9:C3:A7:21:51:0B:64:EC:76:4D:01:D3:D0:94:EB:95:41:61:B6:25:44:EA:8F:18:7B:59:53`）
