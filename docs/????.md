# RGPlayer 使用说明（v2.0.0）

面向 ANBERNIC RG Rotate（720×720 方屏、Android 12）的本地视频播放器。v2.0.0 起播放内核为 libVLC，兼容性更好。与 MX Player 没有任何依赖或联动。

## 安装

- APK：`RGPlayer-2.0.0.apk`（本目录）
- 安装：复制到机器上点击安装，或 `adb install -r RGPlayer-2.0.0.apk`
- 首次启动需授予「媒体/视频」读取权限；授权后自动扫描视频
- 从 1.x 升级：因签名更换，需要**先卸载旧版**再安装 2.0.0

## 更新

设置 → 更新 → 点「检查」，有新版本时按钮变「下载」，下载完成变「安装」。APK 保存到系统 `Download/RGPlayer-<版本>.apk`。

## 界面

- 首页：视频所在目录的上一级；点文件夹进入下一层；左上角返回逐级向上
- 视频卡片：封面（自定义图片或首帧）、时长
- 单文件夹会自动展开，不显示外层文件夹

## 播放与手势

- 单击画面：显示 / 隐藏控制层
- 双击：暂停 / 继续
- 左右拖动：拖动进度，带关键帧预览，进度条跟随
- 左 1/4 上下滑：亮度；右 1/4 上下滑：音量
- 长按画面后左右滑：0.5X–4.0X 调速，松手保留
- 双指捏合：1X–4X 缩放（右下角出现「还原」）
- 屏幕左右边缘横滑：直接退出播放页

## 菜单

返回键（或长按播放键）打开菜单：

- 画面比例：自动 / 铺满 / 16:9 / 4:3 / 原始
- 播放速度：0.5X–4.0X
- 旋转：0° / 90° / 180° / 270°（旋转时自动切软解）
- 字幕：内嵌字幕列表、关闭字幕、加载字幕文件
- 音轨：多音轨切换
- 视频信息：路径、大小、码率、解码/丢帧统计、轨道列表

## 字幕

- 自动加载视频同目录、同名外挂字幕：`.srt` `.ass` `.ssa` `.vtt` `.sub`
- 白字黑描边，无黑底
- 可选「关闭字幕」或手动加载字幕文件

## 手柄

- A / 回车 / 空格：播放 / 暂停
- B：退出播放器
- 返回键：打开 / 关闭菜单
- 十字左右：快退 / 快进 10 秒
- 十字上下：上一部 / 下一部
- L1 / R1：上一个 / 下一个视频

## 设置

- 默认画面比例、媒体目录（可选择只显示某个目录）、内置字体开关
- 隐藏 .nomedia 目录（目录含 .nomedia 的视频不扫描）
- 更新、说明、清除缓存

## 封面

- 与视频同名：`Movie.mkv` → `Movie.jpg` / `.jpeg` / `.png` / `.webp`
- 目录级：`poster.jpg`（该目录所有视频共用）
- 没有封面时临时读取视频首帧（纯黑/纯色会跳过），只放内存，不生成文件
- 设置 →「清除缓存」可清除封面缓存与预览缓存

## 回滚

- 本项目不修改系统，也不动其它播放器的数据
- 回滚旧版本：先卸载当前版本，再安装保存的旧 APK
- 签名更换后，旧版与新版的设置数据不共享
